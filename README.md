# Aplicación Web Interactiva con React y Google Maps

Aplicación web multipágina desarrollada con **React (Vite)** como parte de proyectos prácticos de desarrollo frontend. La plataforma incluye navegación entre distintas vistas y la integración de la API de Google Maps para funciones geoespaciales interactivas.

# Características Principales

- **Arquitectura Multipágina:** Estructura modular de páginas y componentes (Home, Contacto, Acerca de, etc.)
- **Integración con Google Maps API:** Visualización de mapas interactivos, gestión de rutas (`RutaGoogleMaps.jsx`) y herramientas de dibujo sobre el mapa (`DrawingMap.jsx`)
- **Estilos Dinámicos:** Hojas de estilo CSS personalizadas e independientes para cada vista y componente.

para ejecutar la aplicación

1. npm install
2. npm run dev
